# v114 本地闹钟按键动作主机记录

## 结论

提交 `7c5ee52c6d098f259101a0c6c94efd1f3e7992d5` 将中央键接到计时器、闹钟、当前音频和配网的
单一产品动作状态机。代码与完整主机门禁通过；本轮未连接 HA、ADB 或首台 R1，真实中央键消息、
扬声器停止、稍后提醒持久化和操作时延仍待自动实机验证。

## 按键映射与固件边界

- 没有日历闹钟响铃时，中央键单击立即停止正在响铃的计时器；若没有响铃，则沿用统一
  `USER_STOP` 取消当前回答、播报或媒体音频。
- 日历闹钟响铃时，首个单击进入固定450毫秒判定窗口：窗口到期执行停止；窗口内第二次单击
  取消待执行停止，并按每项本地保存的 `snooze_minutes` 稍后提醒。双击不会先写入停止状态。
- 多个日历闹钟同时响铃时，单击停止全部，双击逐项沿用各自稍后分钟数。计时器和日历闹钟的
  响铃所有权仍彼此独立。
- 中央键长按继续打开原厂配网页面。3448固件会让 `SystemTool/NetControl` 同时处理长按消息，
  普通卫星 APK 无法可靠阻止该副作用，因此没有把长按伪装成闹钟稍后提醒。

## 失败关闭与状态回读

- 闹钟停止持久化失败时，本地响铃已经停止；状态机记录失败，但不会继续取消无关的回答或媒体。
- 稍后提醒持久化失败时保持闹钟响铃，不降级为停止，也不意外打开配网。
- shell能力快照新增 `button_actions`，回报最后动作、停止/稍后/取消音频/配网次数、失败原因与
  单击是否仍在判定窗口。服务销毁会撤销未决回调，避免旧服务在重启后执行按键动作。
- 本实现只消费固件既有 `what=256,arg1=1/5` 消息，不新增按键节点权限，不要求用户执行物理验收。
