# v116 设备友好名称与 Area 主机记录

日期：2026-09-13  
范围：HA集成0.13.0；未连接生产HA、ADB或真实R1

## 结果

- HA设备注册表是友好名称和Area的唯一来源。HA页面修改后，语音查询直接读取同一注册表；语音修改也直接写入该注册表，不在Android或集成中保存第二份名称/区域。
- 中文入口只接受明确指向当前R1/音箱的查询与修改。来源`device_id`必须等于该集成按固定MAC解析出的设备ID，不能从另一台设备修改。
- 支持查询名称、查询区域、修改名称、分配HA中已有的唯一同名区域，以及清除区域。不会由语音隐式创建区域。
- 名称限制为1～64个可显示字符；空值、控制字符、不存在区域和歧义区域均拒绝。写入后立即从注册表回读，未确认时明确返回失败，不反馈成功。
- 友好名称变化只更新`name_by_user`。设备registry ID、Android协议节点名、Noise身份、MAC绑定和由协议节点名生成的ESPHome服务名不变，因此改名后仍定位到原设备。
