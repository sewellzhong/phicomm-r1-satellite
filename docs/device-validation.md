## 优化任务的后续验证

下表来自[优化分析](2026-09-07-r1-chain-optimization.md)，仅登记未来场景，不代表已有受测功能或本次运行测试。以下各项受测提交/APK/HA 版本均待实现后填写，主机结果均为“未运行”，实机状态均为“待验证”。开发保留必要最小检查，完整语音、网络/IP 和 72 小时验收仍按最终候选顺序执行。

| 任务 | 主机/模拟检查 | 实机或真实后端待验场景 |
| --- | --- | --- |
| O1 | 关联、单调时间、容量及隐私 | 诊断开销、帧预算、首块/排空/续听时间口径；未经校时不直接比较跨端时间 |
| O2 | 取消、迟到事件、重复停止、恢复策略 | 按键/新唤醒/直接插话分别达标，旧音频不复活，媒体/闹钟/通知共存 |
| O3 | 增量文字到 TTS、工具等待、失败取消 | 至少 60 秒首段早于全文生成开始播放，无丢句/重播/卡死；执行确认前无成功播报 |
| O4 | 同值旧缓存、离线、过期、重复/并发写入 | 双入口确认、重连收敛和重启持久化，不误报成功 |
| O5 | 记忆与续听独立过期、来源隔离、确认状态 | 实际后端上下文、普通“好”与待确认操作；历史失败不被模拟覆盖 |
| O6 | 接口存在/变化/缺失、加载卸载恢复 | 固定 HA 版本与对应组件的设备状态同步 |
| O7 | 修改端点策略时做边界检查 | 最终语音回归验证停顿、短句、慢速表达、截句及延迟；1.8 秒默认与目标差距保持开放 |
| O8 | 转换格式、语速缓存、部分写入、缓冲压力 | 首音、语速/音调、欠载/高水位、长回答和取消效果 |
