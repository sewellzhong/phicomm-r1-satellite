# R1 更新监督器持久运行时主机记录（2026-09-13）

## 本轮范围

在U1失败关闭策略之上实现不依赖候选APK进程的持久运行时基础，代码位于`android/update-agent/src/update_runtime.*`。本轮只处理可在主机严格验证的事务落盘、崩溃恢复、客户端身份准入和候选APK字节落盘；没有连接R1、ADB或HA，也没有实现或调用PackageManager。

受测实现提交为`7cf48b615689c8acd1ce5e0ff049bbd4b1061e14`。

## 已实现边界

- 事务目录必须是监督器有效UID拥有的真实目录且权限不宽于0700；状态与候选文件固定0600，拒绝不安全的符号链接或异主文件。
- 状态先写同目录临时文件，完成文件`fsync`后原子替换正式状态，再对目录`fsync`；安全的崩溃遗留临时文件可以恢复清理，不安全临时节点失败关闭。
- `TransactionController`把策略转换和持久化绑定：`installing`必须在调用者获准执行包替换前落盘；身份不符、部分健康、超时或重启触发的回滚决定在调用降级前落盘；成功更新或验证完成的回滚才移除活动事务。
- 监督器在`installing`阶段崩溃后读取事务时固定转换为`rolling_back`并再次持久化，不重试结果不明确的安装。
- 本地socket监听器未来必须从`SO_PEERCRED`取得UID；本轮的准入函数只接受与配置卫星UID精确相等的值，root及其他特权UID没有隐式旁路。
- 候选只接受已经传入的普通文件描述符，不接受客户端路径，不接受pipe/socket；落盘名只由已验证的32位小写十六进制操作ID生成。
- 候选限制4 KiB～64 MiB，前后复核来源文件身份/大小，按固定偏移复制并计算内置SHA-256；哈希或长度不符时删除临时文件。验证成功后以`link`发布且不覆盖既有候选，再同步目录。
