# 版本 41：无命令误回复的文本检查

用户在Alexa唤醒后没有输入命令，HA调试显示STT为“。”，随后播报“抱歉，我无法理解您的意思”。
版本40把识别文字trim后仅检查非空，纯标点仍会发起intent→tts，这是已确认的实现缺口。
只读状态显示运行仍在listening且没有连接错误；这些计数不包含音频，不能据此确定VAD
被尾音、背景声还是其他输入触发。本轮不盲目调整VAD模式或门限，也不采集家庭音频。

## 修正

`SttCommandText` 按Unicode码点检查识别结果。没有任何字母或数字的结果被视为无命令，
包括空白、纯标点、纯符号及格式标记；保留含有中文/字母/数字的原文，不删除设备名或内部标点。
“停”“好。”“5”“５”等短结果仍有效。不将有文字但不认识的请求直接吞掉。

STT结果“。”会转换为本地空命令；等待STT运行结束后直接通知整轮结束并回到listening，
不发起意图请求、不请求TTS、不额外播放退出语，也不主动关闭已认证连接。
这能拦截本轮已知结果，但不保证过滤Whisper可能产生的含真实文字的幻觉。
VAD仍可能被环境声音触发上传；这与“纯标点不得触发回复”是不同的待验证问题。
