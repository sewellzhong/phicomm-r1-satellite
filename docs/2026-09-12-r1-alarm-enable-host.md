# v112 中文闹钟启停与多闹钟主机记录

日期：2026-09-12

## 结论

提交 `9b0cc531d6c0ef7262425ea20484444ba6047863` 在 `r1_input_guard` 0.11.0 中补齐按
唯一名称启用、开启、打开、停用、禁用或关闭本地闹钟的中文入口。写入复用既有 Noise
认证服务、请求关联、乐观版本、R1 完整回读和离线待同步路径；重复设置为已有状态保持
幂等，不产生无意义版本写入。离线变更只回答“待同步、尚未送达”，不反馈为 R1 已确认。

R1 本地内核继续允许最多 32 个独立闹钟。新增主机测试固定两个同一时刻到期的闹钟：
两项均保留独立 `ringing` 状态，只启动一个共用输出，停止其中一项不停止另一项，直到最后
一项停止才释放铃声。中文查询也会逐条返回多个闹钟的名称、日程和启停状态。

本轮没有连接生产 HA、R1 或 ADB。设备仍运行 v28 代理和 v102 APK；本记录是代码和主机
结果，不是实机交付结论。

## 边界

- “多条到时提示”当前实现为多条独立命名闹钟/提醒及各自的到期、响铃、停止和稍后提醒
  状态，不会因为同一时刻到期而覆盖。
- 当前离线输出仍是通用本地合成铃声，不包含动态中文名称播报；每项独立铃声、音量和动态
  提示内容尚未实现，不能把多闹钟状态支持写成这些能力已经完成。
- 修改或启停只接受唯一名称；同名多项继续失败关闭并要求先在 HA 中使用唯一名称，避免
  批量误操作。
