# Phicomm R1 Voice Satellite

2026-09-06：Home AI 名称整理将过滤集成改为“语音识别与无效输入过滤”，STT 实体显示为“语音识别（Whisper＋无效输入过滤）”（0.1.1）。实体 ID 与过滤逻辑不变；当前 HA 两条管线仍选择原 Whisper。见 名称变更与验收（关联项目文档，仅家中可用）。

将斐讯 R1 改造为 Home Assistant 中文语音卫星的落地项目。

## 当前需求

- 端侧唤醒词唯一固定为英文单词 `Alexa`，无前缀。
- 使用 ESPHome 官方模型库的现有 Alexa microWakeWord v2 预训练模型，停止 Camila 自训练路线。
- 唤醒后的 STT、意图/对话和 TTS 全部使用中文，不做自动语言检测。
